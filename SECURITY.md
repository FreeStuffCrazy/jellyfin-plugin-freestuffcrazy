# Security policy

This plugin holds a link credential and forwards viewers' requests to a Jellyfin
server, so security reports are welcome.

Please report a vulnerability privately through this repository's
**Security → Report a vulnerability** form on GitHub, not in a public issue.
Include the plugin and Jellyfin versions and steps to reproduce. You can expect
an acknowledgement, and a fix or a decision before anything is disclosed
publicly.

In scope: the plugin in this repository and its wire protocol
([`PROTOCOL.md`](PROTOCOL.md)). The hosted relay and FreeStuffCrazy Player are
separate services.
